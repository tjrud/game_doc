# 전투 시스템

## 개요

### 전투 방식
게임의 전투가 진행되는 방식

### 핵심 요소
- 턴 방식 vs 실시간
- 플레이어 제어 방식
- 난이도 표현

## 배경

### 전투 시스템 선택 이유
- 게임 장르와의 일치
- 플레이어 스킬 표현
- 게임 페이싱

### 게임 경험과의 연결
- 핵심 게임플레이
- 성취감 제공
- 난이도 조정 방법

## 상세 설계

### 전투 구조

**전투 개시**
- 조우 방식
- 선제 조건
- 도주 가능성

**턴 구성** (턴 방식인 경우)
- 행동 선택 방식
- 실행 순서 결정
- 턴 시간 제한

**실시간 전투** (실시간인 경우)
- 조작 시스템
- 카메라 각도
- UI 표시

**전투 종료**
- 승리 조건
- 패배 조건
- 도주 옵션

### 행동 체계

**기본 행동**
1. 공격
   - 범위
   - 데미지
   - 소비
2. 방어
   - 효과
   - 기간
   - 추가 효과
3. 스킬
   - 종류
   - 효과
   - 소비

**아이템 사용**
- 회복
- 버프
- 소비 조건

**도주**
- 성공 확률
- 조건
- 페널티

### 속성 시스템

**속성 종류**
1. 속성 1
   - 특징
   - 우위 관계
   - 약점
2. 속성 2
   - 특징
   - 우위 관계
   - 약점

**상성**
```
속성A > 속성B > 속성C > 속성A
```

### 상태 이상

**상태 1: 독**
- 발생 조건
- 지속 시간
- 효과
- 해제 방법

**상태 2: 마비**
- 발생 조건
- 지속 시간
- 효과
- 해제 방법

## 구현 고려사항

### 난이도 곡선
- 초반 접근성
- 중반 재미
- 후반 도전성

### 플레이어 선택지
- 전술 깊이
- 다양한 해결책
- 롤플레이 가능성

### 기술적 구현
- 성능 최적화
- 네트워크 동기화 (멀티플레이인 경우)
- UI/UX
