# 능력치 및 수치

## 개요

### 수치 체계
게임의 모든 수치 계산 방식의 통합 규칙

### 목표
- 플레이 밸런스
- 성장 체감도
- 게임 난이도 조정

## 배경

### 수치 설정의 필요성
- 게임 메커닉의 기초
- 플레이 공정성
- 개발자의 게임 조정 도구

### 게임 장르와의 연결
- 장르적 기대치
- 시뮬레이션 vs 액션

## 상세 설계

### 기본 능력치

**체력 (HP)**
- 최대값 계산식
- 회복 방법
- 스텟 영향

**마나/에너지**
- 최대값 계산식
- 회복 속도
- 사용처

**공격력 (ATK)**
- 계산식
- 장비 영향
- 버프 계산

**방어력 (DEF)**
- 계산식
- 감소 효과
- 스텟 영향

**속도 (SPD)**
- 영향 범위
- 계산 방식
- 상한선

### 특수 능력치

**치명타 (CRI)**
- 기본 확률
- 증가 방법
- 데미지 배수

**회피 (EVA)**
- 기본 확률
- 증가 방법
- 제약 조건

**저항 (RES)**
- 원소별 저항
- 상태 이상 저항
- 계산 방식

### 수치 계산식

**데미지 계산**
```
최종 데미지 = (공격력 - 방어력) × 속성상성 × 치명타배수 × 상태보정
```

**경험치 계산**
```
경험치 = 몬스터레벨 × 기본값 × 난이도보정
```

**성장 곡선**
- 선형 vs 지수
- 후반부 조정
